# Support

Rafiq is maintained by a small team on a best-effort basis. We read everything, but we cannot promise response times.

| You want to | Go to |
|---|---|
| Ask a question or share an idea | [GitHub Discussions](https://github.com/tatawurAI/rafiq/discussions) |
| Report a bug | A [bug report](https://github.com/tatawurAI/rafiq/issues/new?template=bug_report.yml) |
| Request a feature | A [feature request](https://github.com/tatawurAI/rafiq/issues/new?template=feature_request.yml) |
| Report a security problem | [SECURITY.md](SECURITY.md), never a public issue |
| Report a conduct problem | conduct@tatawur.ai, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Before you file a bug, search existing issues and check that you run the latest release. Include your bridge version, the app version, your server OS and the phone model. Redact tokens and private paths from logs.
