# Test vectors for the bridge's allow-list of key encodings (TerminalInputFilter).
# One per line: <verdict> TAB <bytes> TAB <note>. Lines starting with # are comments.
#
# verdict: accept  the frame passes through unchanged
#          reject  the frame is dropped entirely
#          split   frames separated by " | " are sent one after another, and together pass unchanged
# bytes:   \e is Escape, \r \n \t as usual, \xHH one byte, \\ a backslash, anything else is itself (UTF-8).
#
