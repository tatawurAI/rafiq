`rafiq-bridge setup` sets up your server in one command. It finds your `*.ts.net` name, checks that Claude Code and `claude-agent-acp` are installed, writes the settings it found to `~/.config/rafiq/bridge.conf` after asking about each one, offers to run `tailscale serve` and to install the bridge as a service, prints where every setting came from, and ends with a pairing QR code. The bridge now reads `bridge.conf`, and environment variables still win over it. `rafiq-bridge service install` runs the bridge as a launchd agent on macOS or a systemd user unit on Linux.
